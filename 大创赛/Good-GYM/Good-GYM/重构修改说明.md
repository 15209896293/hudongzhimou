## 现有文件修改步骤

### 步骤1：修改 `app/main_window.py`

**目标**：从474行瘦身到约150行，只保留UI布局、信号连接、生命周期。

**具体修改**：

1. **删除所有状态变量**（12个），改为从 `AppState` 读取
   - 删除：`self.device`、`self.model_mode`、`self.exercise_type`、`self.current_count`、`self.manual_count`、`self.is_resetting`、`self.current_keypoints`、`self.current_fps`、`self.current_angle`、`self.current_angle_point`、`self.current_inference_frame`、`self.start_time`

2. **删除所有业务方法**（20+个中转方法），改为调用 `AppController`
   - 删除：`change_exercise`、`reset_counter`、`increase_counter`、`decrease_counter`、`confirm_record`、`change_camera`、`toggle_rotation`、`toggle_skeleton`、`toggle_mirror`、`change_device`、`change_model`、`switch_to_workout_mode`、`switch_to_stats_mode`、`switch_to_voice_control_mode`、`open_video_file`、`switch_to_camera_mode`、`show_about`、`change_language`、`update_goal`、`update_weekly_goal`、`load_month_stats`、`update_today_stats`、`update_stats_overview`

3. **删除 `update_image()` 方法**（约50行），改为调用 `AppController.on_frame_received()`
   - 删除帧忙锁、安全检测节流、语音播报逻辑（这些已移入 `FramePipeline`）

4. **修改 `__init__`**
   - 创建 `AppState` 实例
   - 创建各 Manager 时传入 `AppState` 而非 `self`
   - 创建 `FramePipeline` 实例
   - 创建 `AppController` 实例
   - 修改 `connect_signals()`：所有UI信号连接到 `AppController`

5. **保留的内容**
   - `setup_ui()`：UI布局不变
   - `connect_signals()`：但信号目标改为 `AppController`
   - `setup_video_thread()`：创建 VideoThread，但把 `main_window = self` 改为 `app_state = self.app_state`
   - `start_video()`：启动视频线程
   - `closeEvent()`：调用 `AppController.shutdown()`

6. **关键修改点**：VideoThread 的引用
   ```python
   # 修改前
   self.video_thread.main_window = self
   
   # 修改后
   self.video_thread.app_state = self.app_state
   ```

## 关键风险提醒

### 必须遵守的6条约束

1. **安全检测节流计数器必须在 FramePipeline 顶层管理**
   - `FramePipeline._safety_frame_counter` 在 `process_frame()` 入口每帧递增
   - 不能放在 `_stage_safety()` 内部

2. **mirror_mode 变更时必须同时更新 VideoThread**
   - `video_processor.toggle_mirror()` 内部调用 `video_thread.set_mirror()`

3. **推理跳帧计数器初始值保持为1**
   - `FramePipeline._inference_frame_counter = 1`（确保首帧推理，触发模型延迟加载）

4. **ModeManager 保留对 main_window 的布局操作引用**
   - `switch_to_workout_mode()` 和 `switch_to_stats_mode()` 中的布局操作需要 main_window

5. **设备/模型切换的回滚逻辑必须覆盖所有相关组件**
   - VideoThread.stop()、PoseProcessor.update_device()、AppState.device

6. **VideoThread 的 current_inference_frame 写入目标改为 AppState**
   - `self.app_state.current_inference_frame = inference_frame`
