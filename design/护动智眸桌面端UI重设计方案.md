# 护动智眸桌面端 UI 重设计方案

## 一、当前痛点诊断

### 1.1 视觉层面
- **深色纯黑背景** (#000000) 在投影仪上过于刺眼，远距离观看对比度过强
- **布局紧凑**，右侧 520px 内堆叠 4 张卡片（安全面板 + 计数器 + 设置 + 开关 + 按钮 + 用户档案），信息密度过高
- **控件重叠**，窗口缩小或不同分辨率下间距不够，控件挤在一起
- **视频区骨架线简陋**，只有科研级别的线条和角度数字，没有产品级的视觉包装

### 1.2 功能层面（不在本次设计范围，但需要指出）
- 安全检测触发不稳定或提示不清晰
- 视频上只有骨架线，没有「标准动作对比」或「纠正建议叠加」
- 缺乏动作质量评分/反馈闭环

### 1.3 用户场景
- **主要场景**：比赛答辩投屏演示（1920x1080 大屏）
- **次要场景**：作为项目计划的一部分，需要看起来像一个「真正可用的软件产品」
- **核心信息优先级**：视频画面 > 安全警告 > 计数器 > 其他设置

## 二、设计方向：简洁白色系

基于调研 10 组行业顶级健身 UI 设计，结合用户偏好，采用 **Apple Health / Peloton 风格的浅色主题**。

### 2.1 为什么选浅色
1. **投影仪友好**：浅色背景在投影仪上不刺眼，远距离可读性远优于纯黑
2. **产品感强**：深色主题容易看起来像「科研 Demo」，浅色主题更像「正式产品」
3. **安全色对比度更高**：绿/橙/红警告色在白色背景上比黑色背景更醒目
4. **行业趋势**：Apple Fitness+、Keep、大部分消费级健身 App 都以浅色为主

### 2.2 色彩方案

```
背景色:    #F5F5F7  (Apple 式浅灰白，不是纯白)
卡片色:    #FFFFFF  (纯白卡片，带轻微阴影)
表面色:    #F0F0F5  (输入框/按钮底色，比背景略深)
主文字:    #1D1D1F  (近黑，不是纯黑)
次文字:    #86868B  (灰色辅助文字)
三级文字:  #AEAEB2  (更浅的灰)
边框色:    #E5E5EA  (极浅灰边框)
分隔线:    #D2D2D7  (浅灰分隔)

语义色（保留当前，在浅色背景上更醒目）:
  安全/成功:  #34C759  (绿色)
  警告:      #FF9F0A  (橙黄)
  危险:      #FF453A  (红色)
  强调/确认:  #007AFF  (蓝色)
  品牌色:    #34C759  (绿色 — 与安全色统一，传达「健康保护」)
```

### 2.3 字体规范

```
品牌标题:   28px / 700 / -0.5px 字距
面板标题:   17px / 600 / 0px
大数字:     72pt / 200 / -2px 字距（超轻字重，高辨识度）
计数标签:   13px / 500 / 0.5px 字距 / uppercase
正文:       15px / 400
辅助信息:   13px / 400
标签/caption: 11px / 500 / uppercase
```

### 2.4 圆角规范

```
大卡片:     20px（比当前 24px 略收，更精致）
按钮/输入:  12px
小标签/pill: 100px（全圆角）
开关:       14px
```

### 2.5 间距规范

```
页面边距:     24px（比当前 16px 更宽松）
卡片间距:     16px
卡片内边距:   20px
元素间距:     12px（元素之间）
紧凑间距:     8px（相关元素之间）
```

## 三、布局重设计方案

### 3.1 整体布局：左视频 + 右信息面板（7:3 比例）

```
┌─────────────────────────────────────────────────────────────────┐
│  护动智眸                          🏠 运动模式  📊 统计  ⚙️     │  <- 顶部导航栏
├────────────────────────────────────┬────────────────────────────┤
│                                    │  ┌──────────────────────┐  │
│                                    │  │    🟢 安全             │  │  <- 安全面板（简洁版）
│                                    │  │  动作标准，继续保持！  │  │     只保留状态+消息
│                                    │  └──────────────────────┘  │
│          摄 像 头 视 频             │  ┌──────────────────────┐  │
│         + 骨架叠加                  │  │                      │  │
│         + 安全状态条               │  │        0             │  │  <- 计数器（核心）
│         + 角度仪表                 │  │     已完成            │  │     大数字居中
│         + 纠正提示文字             │  │  ↑ 准备  ↓           │  │     阶段指示
│                                    │  └──────────────────────┘  │
│                                    │  ┌──────────────────────┐  │
│                                    │  │ 深蹲            ▼    │  │  <- 设置（紧凑）
│                                    │  │ 轻量模型       ▼    │  │     一行一个下拉框
│                                    │  │ 摄像头 0        ▼    │  │
│                                    │  └──────────────────────┘  │
│                                    │  ┌──────────────────────┐  │
│                                    │  │ 🔲旋转 🟩骨架 🔲镜像│  │  <- 开关区（2x2）
│                                    │  │ 🔲GPU加速           │  │
│                                    │  └──────────────────────┘  │
│                                    │  ┌──────────────────────┐  │
│                                    │  │  [-]  [重置] [确认] [+]│  │  <- 操作按钮
│                                    │  └──────────────────────┘  │
├────────────────────────────────────┴────────────────────────────┤
│  RTMPose · 实时检测  |  30 FPS  |  轻量模型 · CPU              │  <- 状态栏
└─────────────────────────────────────────────────────────────────┘
```

### 3.2 核心改动点

**1. 视频区域增强（最重要）**
- 视频区占 70% 宽度（从 6:4 改为 7:3），让动作画面足够大
- 底部增加 **安全状态渐变条**（4px 高，绿→橙→红渐变，参考 Apple Burn Bar）
- 左上角 overlay 只保留 2 个 pill 标签（RTMPose 实时检测 + FPS），移到视频内部
- **增加动作质量评分**：视频右上角显示 0-100 分的圆环评分
- 骨架线颜色从红色改为 **品牌绿色 #34C759**，在浅色背景上更协调
- 角度数字优化：从「xx degrees」改为大号角度数字 + 小号单位，颜色用蓝色

**2. 安全面板精简**
- 去掉统计行（检测/警告/危险次数），移到统计面板
- 只保留：状态圆点 + 安全等级文字 + 消息内容 + 语音开关
- 消息区域改为 **聊天气泡样式**（AI 教练头像 + 圆角气泡），更有亲和力
- 状态变化时气泡有 **轻微动画**（安全时绿色淡入，危险时红色弹跳）

**3. 计数器放大**
- 大数字从 48pt 增至 72pt，字重从 300 降至 200（超轻字重）
- 计数变化时数字有 **弹跳微动画**（scale 1.0 -> 1.1 -> 1.0）
- 数字颜色用深色 #1D1D1F，不再是白色

**4. 右侧面板限宽 + 滚动**
- 右侧最大宽度 400px（从 520px 缩小），避免控件横向拉伸
- 内容超出时可滚动（加滚动条）
- 卡片间距统一 12px

**5. 顶部导航栏**
- 新增简洁的顶部导航栏，包含：品牌名 + 模式切换按钮（运动/统计）
- 替代当前的菜单栏，更现代化
- 菜单栏的高级选项（语言切换、关于）收入「设置」下拉

**6. 用户档案面板**
- 默认隐藏，通过顶部导航栏的「👤」图标打开
- 以 **侧边抽屉 (Drawer)** 形式从右侧滑出，不占用主布局空间
- 这样右侧面板就只有 5 张卡片，不会挤

## 九、项目建议（额外思考）

基于对整个项目的深入了解，有几点建议：

### 9.1 视频区域的产品化
当前视频区只显示骨架线和角度数字，看起来像科研 Demo。建议：
- **增加动作名称大字叠加**：视频左下角显示当前运动名称 + 标准动作图示
- **角度信息优化**：用半圆仪表盘替代纯数字，更直观
- **安全反馈文字叠加到视频上**：危险时在视频中央显示半透明红色警告文字

### 9.2 安全检测的可靠性
这是产品的核心卖点，如果答辩时安全检测不触发或触发不准，会严重影响评委印象。建议：
- 检查 `exercises.json` 中各运动的安全阈值配置是否合理
- 在安全面板增加「检测灵敏度」滑块，让演示时可调
- 准备一个「必然触发」的演示动作（比如深蹲到很浅的角度）

### 9.3 比赛答辩的演示策略
- 进入时展示用户档案录入 → 展示个性化阈值生效（受伤用户阈值自动收紧）
- 训练过程中故意做一个不规范动作，让安全检测触发 → 评委能直观看到差异化
- 最后展示统计面板的历史数据 → 完整闭环

### 9.4 统计面板的改进
- 增加日历热力图（类似 GitHub 贡献图），显示每日训练密度
- 增加「7 天安全趋势」折线图
- 目标设置改为可视化进度条 + 滑块
